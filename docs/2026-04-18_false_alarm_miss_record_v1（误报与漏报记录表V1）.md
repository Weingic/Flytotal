## 为什么暂不再调阈值

阈值增大通常减少误触发，但会继续降低召回；阈值减小会提高召回，同时增加人物、车辆、飞机和鸟类触发。V4b 已在 `0.45` 完成独立评测和运行时部署，真实矩阵完成前不为追求好看结果临时改阈值。

真实结果计算：

```text
无人机召回率 = 检出的无人机试验数 / 无人机总试验数
负样本误锁率 = 出现 YOLO_AUTO 无人机锁定的负样本试验数 / 负样本总试验数
漏检率 = 1 - 无人机召回率
```

不能只按单帧检测框统计成功。正式“检出”至少要求连续确认并进入 `YOLO_AUTO`；短暂单帧触发单独记录为瞬时误触发。
